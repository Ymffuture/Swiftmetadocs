# ClassTour

> **Status:** Coming Soon

ClassTour is an upcoming interactive learning platform designed for Grade 11–12 learners in South Africa, covering:

- **Mathematics**
- **Physical Sciences**
- **Life Sciences**

## Overview

ClassTour leverages interactive tools and live communication to help senior secondary learners master key concepts in their studies. Built by SwiftMeta, it combines engaging content with the proven communication platform of SonaTG.

## Target Audience

- Grade 11 learners
- Grade 12 learners (Matric)
- Educators and tutors
- Parents supporting learner development
